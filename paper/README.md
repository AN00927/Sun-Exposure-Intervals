# paper/

The manuscript for the vitamin D sun-exposure scheduling model in this
repository: *Splitting, not front-loading, sets the plateau: dose-response
concavity aligns the vitamin D optimum with the skin-cancer optimum in
sun-exposure schedules.* Authors and affiliations are in the `\author` /
`\affil` block of `manuscript.tex`.

## Files

| File | What it is |
|---|---|
| `manuscript.tex` | The paper. Plain `article` class (not `elsarticle`), `natbib` numeric citations, `vancouver` bibliography style. |
| `references.bib` | Bibliography. Holds more entries than the text cites; see [Bibliography](#bibliography). |
| `manuscript.pdf`, `*.aux`, `*.bbl`, `*.blg`, `*.log`, `*.out`, `*.spl` | Build products, gitignored (`.gitignore`, `paper/*` block). |

Nothing else in this directory is part of the build.

## Build

Needs a TeX distribution with `natbib`, `authblk`, `siunitx`, `microtype`,
`lmodern` and `vancouver.bst` (all in stock MiKTeX / TeX Live; MiKTeX
fetches missing packages on first run).

```bash
cd paper
latexmk -pdf manuscript.tex
```

or by hand: `pdflatex manuscript` → `bibtex manuscript` → `pdflatex
manuscript` → `pdflatex manuscript`. Last clean build: 2026-09-23, 18 pages,
no undefined references or citations. Check `manuscript.log` for
`undefined` and `Overfull` after any edit.

## Where the numbers come from

Every quantitative statement in the text is read from the pipeline's
generated outputs: `RESULTS.md` and the CSVs under `tables/`, both
written by `run_all.py`. None is computed in the paper and none should be
typed in from memory or from a doc.

- **After any calibration change, re-run the pipeline and then resync the
  paper.** Run `PYTHONIOENCODING=utf-8 python3 run_all.py` from the repo
  root, then find each number in the text again in the regenerated output.
  The last full resync was 2026-09-23, against the re-anchored `K_const` /
  `A` parameter set.
- **Sign conventions come from the code, not the prose.** For example, the
  free-vs-uniform spacing risk percentages in Results are
  `(uniform − free) / uniform` (`vitd_optimization_reports.py`), so a
  positive value is a *reduction*. An earlier draft inverted that sign.
- **Parameter values are not restated here.** Their only canonical source
  is the `vitd_model.py` module docstring (and `vitd_scenario.py` for the
  frozen exposure scenario), per `CLAUDE.md`. The paper describes the model
  structure and cites that source rather than carrying a parameter table.
- **Validation counts** in *Validation status, disaggregated* must match the
  current `run_all.py` output. Do not carry a count forward from an older
  run.

## Structure

- Abstract and Author summary.
- **1 Introduction**
- **2 Methods:** model structure; frozen reference scenario; objective
  hierarchy and its safeguards; experimental arms; mechanism ablation;
  skin-cancer risk model; constrained optimisation; sensitivity and
  identifiability.
- **3 Results:** concentration vs splitting of a fixed budget;
  redistribution over a horizon; front-loading; the conflict between the
  plateau and transient measures; the concavity ablation; the vitamin D and
  risk optima coinciding (the paper's one table, `tab:riskaware`);
  conditionality of "daily"; feasibility; what the model does not pin down;
  the failing held-out test; the disaggregated validation status.
- **4 Discussion**, **5 Limitations**, **6 Conclusions**.
- Declarations: data and code availability, ethics, clinical disclaimer,
  CRediT, competing interests, funding, use of AI tools.

The manuscript has no figures yet. Candidates already exist under `figs/`
(generated by `run_all.py`). Any figure added should be pulled from there,
not redrawn.

## Bibliography

`references.bib` is deliberately a superset of what the text cites. It also
records the repo's evidence base: sources read and verified, but not yet
woven into prose. On 2026-09-23 the text cited 18 of the bib's 82 entries.
Uncited entries are not errors. They fall into three groups:

- **Section (g), FST V-VI field dosimetry, read but not cited:**
  `nkogatse2019`, `blesic2016`, `blesic2020`. They exist so that the repo
  no longer claims this literature is absent; none feeds a parameter. See
  the section's header comment, and `docs/SOURCES.md`.
- **Evidence behind the model code:** calibration and validation sources
  cited in `vitd_model.py`, `vitd_validation.py` and
  `calibration_approval.yaml`, but not named in the paper's prose.
- **Named data gaps:** `eadie2021` and `plosone2023` are placeholder
  `@misc` entries with `TODO verify` titles. The papers themselves are not
  in the repo.

To see the current cited/uncited split, compare the keys in every
`\cite...{}` in `manuscript.tex` against the `@type{key,` lines in
`references.bib`.

Some sources are referred to in the text by name but have no bib entry:
Moan 1989, Gandini 2005, Weinstein & Van Scott 1965 / Rothberg 1961, and
Kallioglu 2024 (*Sci Rep* 14:3541). A verified entry has to be added
before any of them can be `\cite`d. `rhodes2010` is in the bib but is not
yet cited.

Rules for editing the bib:

- **Never fill a field from memory.** Verify volume, pages, DOI and PMID
  against PubMed or the publisher record, and note the check in a comment.
  An incomplete entry with a visible `TODO verify` is better than a wrong
  one that looks complete.
- **Watch the name collisions.** This repo has hit the same trap three
  times: same first author, same year, different paper.
  - `fajuyigbe2018` (FASEB J) vs `fajuyigbe2018photochem` (Photochem
    Photobiol).
  - `matsuoka1990jlcm` vs `matsuoka1990jaad`.
  - Young 2019/2020 and Alaluf 2001/2002.

  Key such entries apart, and never merge them.
- **Removed entries leave a comment.** A deleted entry keeps a `[REMOVED
  <date>]` comment in its place (e.g. the former `rhodes2017`), so nobody
  searches again for a paper that does not exist.
